Supported Formats

We support the main 3D file formats used in game development, 3D printing, and digital content creation.

Format Guide

GLB / GLTF

The modern standard for 3D on the web. GLB packs everything into one binary file. GLTF keeps JSON and assets separate.

  • Best for web and real-time apps
  • Supports PBR materials
  • Includes animations
  • Widely supported

STL

The standard for 3D printing. It stores triangle geometry without colors or textures.

  • Universal print format
  • Binary or ASCII options
  • No material data
  • All slicers support it

3MF

A modern 3D printing package. This browser converter exports clean geometry-only 3MF files at real-world millimeter scale.

  • Modern print package
  • Millimeter scale export
  • Works with slicers
  • Geometry-only output

OBJ

A legacy format with strong compatibility. It stores geometry and can reference external material files.

  • Maximum compatibility
  • Text-based and editable
  • Separate material files
  • Good for DCC apps

FBX Import Only

Industry standard for animation and game engines. FBX files can be imported and converted to other formats, but exporting TO FBX is not supported in browser-based tools.

  • Full animation support
  • Industry standard
  • Import and convert to GLB/STL/OBJ
  • Export to FBX requires desktop tools

USDZ

Apple's format for AR Quick Look on iPhone, iPad, and Vision Pro. Self-contained archive with geometry and textures.

  • Apple AR Quick Look
  • Safari preview support
  • Self-contained archive
  • Vision Pro ready

Frequently Asked Questions

Everything you need to know about the TimrX converter workflow.

FAQ

Is my data safe?

Yes. File processing runs in your browser using local JavaScript and WebGL. Nothing is uploaded to TimrX servers.

What is the file size limit?

Files under 100MB are recommended for the smoothest experience. Larger files may work, but performance depends on your device.

Are textures preserved?

Textures are preserved for GLB and GLTF exports. STL and OBJ do not support embedded textures in the same way.

Can I convert animations?

Animation data survives only in compatible formats like GLB, GLTF, and FBX. STL and OBJ remain static outputs.

Why use this instead of desktop software?

It is instant, private, and works on any modern browser. Use it for quick conversions without opening Blender or another desktop app.

Need batch conversion?

This page handles one file at a time. For large batch jobs, a scripted desktop workflow is still the better choice.
