# TimrX

TimrX is a browser workspace for 3D modeling, image generation, video generation, file conversion, and 3D print preparation.

Use it to create and refine assets from text prompts or reference images, preview models in the browser, remesh and texture geometry, prepare print-ready files, and export formats such as STL, OBJ, GLB, GLTF, and USDZ without needing Blender for every step.

## What It Includes

- Text to 3D and image to 3D workflows
- Image and video generation tools
- 3D model preview in the browser
- Remesh, texture, rigging, and animation workflows
- STL, OBJ, GLB, GLTF, FBX, and USDZ export support
- 3D print checks and print-focused model preparation
- Community gallery, asset history, and remix workflows
