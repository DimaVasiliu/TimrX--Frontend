Prompt Tips

01

Structure Your Prompt

Use the formula: Subject + Modifiers + Style

Example: "A fearsome dragon, with polished obsidian scales, glowing red eyes, in dark fantasy style"
02

Be Specific with Materials

Instead of vague descriptions, specify exact materials.

"looks beautiful" "smooth gold metal"
03

One Object at a Time

Focus on a single subject for best results. Combine multiple assets later in Blender or Unity.

04

Use Pose Keywords

For characters, add pose terms for rigging-ready models.

T-pose A-pose dynamic action
05

3-6 Key Details

Keep it focused. Too many details dilute the output. Prioritize what matters most.

06

Style Keywords

Add artistic direction for cohesive results.

low-poly realistic cartoon voxel

Pro tip: Mention scale, silhouette, era cues (retro-futurism, dieselpunk), and finish (matte ceramic, lacquered wood) for refined results.

API Snippets

JavaScript 
// Text to 3D Generation
const response = await fetch('https://3d.timrx.live/api/generate', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  credentials: 'include',
  body: JSON.stringify({
    prompt: 'A futuristic robot with chrome armor',
    art_style: 'realistic',
    negative_prompt: 'blurry, low quality'
  })
});
const { task_id } = await response.json();
Python 
# Check generation status
import requests

task_id = "your_task_id"
response = requests.get(
    f"https://3d.timrx.live/api/task/{task_id}",
    cookies=session_cookies
)
status = response.json()
print(f"Status: {status['status']}")
cURL 
# Download generated model
curl -X GET "https://3d.timrx.live/api/download/{task_id}" \
  -H "Accept: application/octet-stream" \
  -o model.glb

About TimrX 3D Print Hub

TimrX 3D Print Hub is an AI-powered online platform for generating 3D models from text descriptions or images. Whether you're a game developer, 3D printing enthusiast, educator, or digital artist, the Hub streamlines your workflow with intuitive tools that require no modelling experience.

Simply describe what you want—or upload a reference image—and let the AI create a detailed 3D asset you can refine, texture, and export.

Export Formats GLB and GLTF formats, compatible with Blender, Unity, Unreal Engine, and popular slicers for 3D printing.

Frequently Asked Questions

What is TimrX 3D Print Hub?

An AI tool that converts text prompts or images into downloadable 3D models—ideal for games, 3D printing, and visualisation.

How do I create a 3D model from text?

Enter a descriptive prompt (e.g., "A futuristic robot with chrome armor") in the workspace and click Generate. The AI processes your request and produces a 3D asset.

What file formats are supported?

Models export in GLB and GLTF—compatible with Blender, Unity, Unreal Engine, and most 3D printing slicers.

Is TimrX free to use?

TimrX uses a credit-based model. New users can explore the interface, and credit packs are available for generating full models.

How long does generation take?

Most models complete in about 3-5 minutes, depending on complexity and current server load.
