Workflow Essentials

Master the three-step process to generate, refine, and share 3D models.

Craft a Vivid Prompt

Lead with silhouette, support with materials, finish with mood.

  • Start with a clear shape or object description
  • Specify materials (metal, wood, ceramic, etc.)
  • Add mood words (sleek, ornate, minimalist, futuristic)
  • Use size cues relative to familiar objects
  • Reference inspiration from real-world designs

Preview & Iterate

Use low-latency preview, wireframe overlay, pin prompts.

  • Preview renders instantly as you refine
  • Overlay wireframe to check topology
  • Pin successful prompts for future batches
  • Use Refine button to adjust proportions
  • Test Remesh for watertight geometry

Publish & Share

Export GLB/GLTF, tag assets, send to Community.

  • Export to GLB/GLTF for any 3D platform
  • Tag assets with keywords and metadata
  • Share to Community gallery for feedback
  • Batch export multiple variations
  • Download textures and maps separately

Pro Tips

Expert techniques to maximize quality and efficiency.

01 — Prompt Specificity

Use Adjectives Strategically

Instead of "nice chair", try "mid-century modern wooden chair with tapered legs and cream fabric upholstery". Specificity breeds quality.

02 — Material Grounding

Reference Real Materials

Anchor your prompts to real-world materials. "brushed titanium" beats "shiny metal". Material knowledge directly affects AI output.

03 — Style Anchors

Name Artistic References

Reference known designers or styles: "Dieter Rams minimalism", "Victorian gothic", "retro-futurism". AI understands cultural context.

04 — Scale Context

Include Size References

Mention comparable objects for scale: "coffee mug-sized", "desk-sized", "car-sized". Relative scale prevents awkward proportions.

05 — Batch Variations

Generate Multiple Styles

Queue 3–5 variations with subtle prompt tweaks. Compare side-by-side to find best aesthetics. Use pinning to save winners.

06 — Post-Processing

Always Remesh First

Run Remesh before texturing. Watertight models export flawlessly to any platform and 3D printer. Quality topology is foundation.
