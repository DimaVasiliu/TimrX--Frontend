┌────────────────────────────────────────────────────────────┐
│ eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.                      │
│ eyJmcmVzaCI6ZmFsc2UsImlhdCI6MTYzNjk4NzY1NCwianRpIjoiOT... │

└────────────────────────────────────────────────────────────┘
  │                      │                    │
  │                      │                    └─ Signature (verifies integrity)
  │                      └────────────────────── Payload (user data)
  └───────────────────────────────────────────── Header (algorithm)

Decoded Payload:
{
  "fresh": false,
  "iat": 1636987654,      ← Issued At
  "jti": "9abc...",       ← JWT ID (for blocklist)
  "type": "access",       ← Token type
  "sub": 1,               ← Subject (user ID)
  "exp": 1636991254       ← Expires (1 hour later)
}

║                          SECURITY LAYERS                                      ║
╚══════════════════════════════════════════════════════════════════════════════╝

Layer 1: Password Security
┌────────────────────────────────────────────────┐
│ Plain Password: "MyPassword123!"               │
│         ↓                                      │
│ bcrypt.hashpw()                                │
│         ↓                                      │
│ Hashed: "$2b$12$eJ5Hzw..."                    │
│ Stored in Database ✅                          │
└────────────────────────────────────────────────┘

Layer 2: JWT Signature
┌────────────────────────────────────────────────┐
│ Payload + Secret Key                           │
│         ↓                                      │
│ HMAC-SHA256                                    │
│         ↓                                      │
│ Signature: "SflKxwRJSMeKKF2QT4fwpMeJf36POk..." │
│ Verifies token wasn't tampered ✅              │
└────────────────────────────────────────────────┘

Layer 3: Token Expiry
┌────────────────────────────────────────────────┐
│ Access Token: 1 hour                           │
│ Refresh Token: 30 days                         │
│ Expired tokens rejected ✅                     │
└────────────────────────────────────────────────┘

Layer 4: Token Blocklist
┌────────────────────────────────────────────────┐
│ On logout: Add JTI to blocklist                │
│ On request: Check if JTI in blocklist          │
│ Logged out tokens rejected ✅                  │
└────────────────────────────────────────────────┘

Layer 5: HTTPS
┌────────────────────────────────────────────────┐
│ All communication encrypted                    │
│ Man-in-the-middle prevented ✅                 │
└────────────────────────────────────────────────┘

Current System (Simple Token):
┌─────────────────────────────────────────────────────────────┐
│ Frontend                    Backend                         │
│    │                           │                            │
│    │  X-Admin-Token: abc123    │                            │
│    ├──────────────────────────>│                            │
│    │                           │ Check if token == env var  │
│    │                           │ Allow if match ✅          │
│    │<──────────────────────────┤                            │
│    │  { posts: [...] }         │                            │
└─────────────────────────────────────────────────────────────┘

Issues:
❌ Token is environment variable (your API key)
❌ Single token for all admins
❌ Can't revoke without changing env var
❌ No user identification
❌ No expiry


JWT System:
┌─────────────────────────────────────────────────────────────┐
│ Frontend                    Backend                         │
│    │                           │                            │
│    │  Authorization: Bearer    │                            │
│    │  eyJhbGci...              │                            │
│    ├──────────────────────────>│                            │
│    │                           │ Decode JWT                 │
│    │                           │ Verify signature           │
│    │                           │ Check expiry               │
│    │                           │ Check blocklist            │
│    │                           │ Get user ID from token     │
│    │                           │ Allow if valid ✅          │
│    │<──────────────────────────┤                            │
│    │  { posts: [...] }         │                            │
└─────────────────────────────────────────────────────────────┘

Benefits:
✅ Each user has unique token
✅ Tokens expire automatically
✅ Can revoke on logout
✅ Identifies which admin made request
✅ Industry standard


╔══════════════════════════════════════════════════════════════════════════════╗
║                         STORAGE COMPARISON                                    ║
╚══════════════════════════════════════════════════════════════════════════════╝

sessionStorage (Current):
┌──────────────────────────────────────────────┐
│ • Cleared when tab closed                    │
│ • Not shared between tabs                   │
│ • More secure (can't steal from other tabs) │
│ • User must login on each new tab           │
└──────────────────────────────────────────────┘

localStorage (JWT Recommended):
┌──────────────────────────────────────────────┐
│ • Persists across sessions                   │
│ • Shared between tabs                        │
│ • User stays logged in                       │
│ • Refresh token enables long sessions        │
└──────────────────────────────────────────────┘
