Prompt Tips

01

Structure Your Prompt

Use the formula: Subject + Modifiers + Style

Example:"A fearsome dragon, with polished obsidian scales, glowing red eyes, in dark fantasy style"
02

Be Specific with Materials

Instead of vague descriptions, specify exact materials.

"looks beautiful" "smooth gold metal"
03

One Object at a Time

Focus on a single subject for best results. Combine multiple assets later in Blender or Unity.

04

Use Pose Keywords

For characters, add pose terms for better results.

T-poseA-posedynamic action
05

3-6 Key Details

Keep it focused. Too many details dilute the output. Prioritize what matters most.

06

Style Keywords

Add artistic direction for cohesive results.

low-polyrealisticcartoonvoxel

Pro tip: Mention scale, silhouette, era cues, and finish for refined results.

API Snippets

JavaScript
// Text to 3D Generation
const response = await fetch('https://3d.timrx.live/api/generate', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  credentials: 'include',
  body: JSON.stringify({
    prompt: 'A futuristic robot with chrome armor',
    ai_model: 'latest'
  })
});
const { task_id } = await response.json();
Python
# Check generation status
import requests

task_id = "your_task_id"
response = requests.get(
    f"https://3d.timrx.live/api/task/{task_id}",
    cookies=session_cookies
)
status = response.json()
print(f"Status: {status['status']}")
cURL
# Download generated model
curl -X GET "https://3d.timrx.live/api/download/{task_id}" \
  -H "Accept: application/octet-stream" \
  -o model.glb

08 / FAQ

Questions, answered.

Everything you need before creating your first asset.

What can I create with TimrX?＋

Images, short videos, textured 3D models and printable assets from prompts, reference images or existing files.

Can I export models for 3D printing?＋

Yes. Use print checks and export workflows for STL and 3MF, then prepare the result for your slicer or print service.

Which file formats are supported?＋

Core workflows support STL, OBJ, GLB, GLTF, USDZ and 3MF. The converter provides additional format paths.

Do I need Blender or advanced 3D skills?＋

No. TimrX is designed to generate, inspect, refine and export assets directly in your browser.

How do credits work?＋

Generation and selected refinement actions use credits. Choose a pack based on the tools and output volume you need.

Can I use TimrX for content, games or products?＋

Yes. Workflows support content creation, game concepts, product visualisation, prototypes and print-ready ideas.
